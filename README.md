# e-plantShopping

## Project Name

e-plantShopping - Paradise Nursery Shopping Application

## Project Description

e-plantShopping is a React-based online plant shopping application developed for Paradise Nursery.

The application allows users to browse a collection of plants, view plant details, add plants to a shopping cart, and manage cart items easily.

## Features

- Browse plants by category
- Three plant categories
- Six unique plants in each category
- Plant images, names, descriptions, and prices
- Add plants to the shopping cart
- Disable the Add to Cart button after adding a plant
- Dynamic cart item count
- Increase and decrease plant quantities
- Remove plants from the cart
- Calculate individual plant totals
- Calculate the complete cart total
- Checkout Coming Soon message
- Continue Shopping functionality
- Responsive and user-friendly interface

## Shopping Cart

The shopping cart dynamically updates when users add, remove, increase, or decrease plant quantities. The application automatically calculates individual item totals and the overall cart total.
